# Labsheet-8
Development of Dynamic and Responsive Websites using HTML and PHP Minor Project
Objective:
• To design and develop a fully functional online Book Store website using HTML and 
PHP.
• To understand the integration of frontend (HTML, CSS) with backend (PHP).
• To implement dynamic features such as product display, user interaction, and basic data 
handling.
• To design a responsive and user-friendly website for a fictional client.
• To apply modern web design principles, accessibility standards, and interactivity.
